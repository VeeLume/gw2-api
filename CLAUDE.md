# gw2-api

Type-safe Rust client for the Guild Wars 2 API v2. The shared foundation for gw2-companion (`../gw2-companion`, depends on this repo via a path dependency) and a future streamdeck-gw2 revival.

## Architecture

Cargo workspace with three crates:

- **`crates/gw2-api-macros`** — Proc macro crate
  - Single unified macro `#[gw2_endpoint(...)]` covering all endpoint shapes
  - `#[gw2_enum]` for flat string enums with `Unknown(String)` catch-all
  - `#[gw2_tagged_union]` for JSON `"type"`-dispatched enums

- **`crates/gw2-api`** — the library
  - Typed IDs (`ItemId`, `RecipeId`, …) generated by `#[gw2_endpoint(id_type = u32)]`
  - Type-level auth states: `Gw2Client<Unauthenticated>` vs `Gw2Client<Authenticated>`
  - Builder-pattern navigation: `client.items().get(id)`, `client.commerce().prices()`
  - **Shared by default across the process:** one `RateLimiter` (`rate_limit::global()`, burst 300, 5/s, `penalize()` on 429) and one static-data `ResourceCache` (`ResourceCache::global()`). The GW2 limit is per IP and static data is the same for every key.
  - `client.authenticate(key)`, `.unauthenticated()`, `.with_language(l)` and `.with_schema_version(v)` derive clients that share limiter and cache
  - Cache stores patched, typed values keyed `(TypeId, base|lang|schema, id)`; `get`, `get_many`, `all` and `pages` fill it; resources marked `auth` bypass it
  - Errors: 403 `"requires scope X"` → `MissingPermission(X)`, other 401/403 → `InvalidToken`
  - Retry: jittered backoff; 429 (1 s base) separate from 502–504 and network errors (2 s base); 500/501 not retried
  - Patch system for permanent API data bugs (`Patchable` trait, `patches/` modules)
  - Endpoint registry via `linkme` distributed slices (used by the CLI)
  - `Coin`, chat-link encoding/decoding (`chat_link.rs`)

- **`crates/gw2-api-cli`** — Developer CLI (`cargo run -p gw2-api-cli -- <cmd>`); reads `GW2_API_KEY` from `.env`
  - `list [--diff]` — list registered endpoints; diff against live `/v2.json` (coverage, auth mismatches, newer schemas)
  - `single [--endpoint PATH|--all] [--keep-going]` — one call per endpoint; auth endpoints without a key are *skipped*, not passed
  - `full [--endpoint PATH|--all] [--concurrency N]` — full data fetch through the typed client
  - `check [--endpoint PATH|--all] [--pinned-only] [--all-langs] [--verbose]` — parse every raw item at the pinned and `latest` schema; reports parse failures by id, ignored fields (`serde_ignored`), ids listed but not returned. Exit 1 on pinned failures.

## GW2 API v2

- Base URL: `https://api.guildwars2.com/v2`
- Auth: Bearer token via `Authorization` header
- Bulk: `?ids=1,2,3` or `?ids=all`, pagination `?page=N&page_size=M` (max 200); a page past the end answers 400
- Rate limit: per IP, burst 300, refill 5/s; no rate-limit headers, 429 on exceeded
- Schema versioning: `?v=<ISO8601>` or `?v=latest`; pinned `2025-08-29T01:00:00.000Z`
- Language: `?lang=en|de|es|fr|zh`

## Macro System

All endpoint types use the single unified `#[gw2_endpoint(...)]` macro. The old separate macros (`#[gw2_resource]`, `#[gw2_singleton]`, `#[gw2_collection_singleton]`, `#[gw2_namespace]`, `#[gw2_method]`) are removed and emit compile errors.

### `#[gw2_endpoint]` flags

| Flag | Effect |
|------|--------|
| `path = "..."` | API path (required). Slash-separated; drives accessor chain and struct naming. |
| `id_type = u32` | Generates `TypeNameId(u32)` newtype + `Resource` impl. The struct needs an `id: TypeNameId` field. Omit for singletons/collections. |
| `paged` | Adds `PagedResource` impl (enables `pages()` / `all()`). |
| `collection` | Fixed-URL endpoint returning `Vec<T>`. |
| `nullable` | With `collection`: returns `Vec<Option<T>>` (e.g. `/v2/account/bank`). |
| `namespace` | Navigation-only handle; generates an accessor but no `.get()`. |
| `auth` | Auth-required; accessor only on `Gw2Client<Authenticated>`. On ID resources also keeps values out of the static cache. |
| `no_registry` | Suppress registry entry (use on error/fallback paths). |
| `no_default_patch` | Suppress generated no-op `Patchable` impl (for types with custom patches). |
| `accessor = ident` | Override the generated accessor method name. |
| `no_accessor` | Suppress accessor generation. |
| `no_trait` | Suppress trait impl generation. |
| `also("path2", ...)` | Register additional paths pointing to the same struct. |

On **async functions**: `#[gw2_endpoint(path = "...")]` attaches the fn to the endpoint struct inferred from the second-to-last path segment. Supports `test_params(key = expr)` for registry smoke tests.

Endpoint handle names come from the last path segment and are per module, so `mounts/skins` (`SkinsEndpoint` in `mounts.rs`) does not clash with `skins`.

## Conventions

- `thiserror` for library errors; endpoints return `Result<T, Gw2ApiError>`
- All API types derive `Debug, Clone, Serialize, Deserialize`
- Typed IDs are auto-generated newtypes: `pub struct ItemId(pub u32);`
- `extern crate self as gw2_api` in `crates/gw2-api/src/lib.rs` — required for proc macro path resolution inside the crate
- Tests never hit the live API: use `wiremock` with `.base_url(server)`, a private `cache_capacity(..)` and a private `rate_limiter(..)` per test (see `crates/gw2-api/tests/client.rs`)
- Live validation is the CLI's job (`check`, `single`), plus `--features verify-patches`

## Development

```bash
cargo test --workspace                           # unit + wiremock tests
cargo test -p gw2-api --features verify-patches  # live patch verification
cargo clippy --workspace --all-targets
cargo run -p gw2-api-cli -- list --diff
cargo run -p gw2-api-cli -- single --all --keep-going
cargo run -p gw2-api-cli -- check --all          # slow
```
